# ✦ ALINKA.VERSE — Алинке 18!

Большое сказочное поздравление с **настоящим обратным отсчётом до 00:00** → **видео** → **интерактивный сайт** с 18 мультвселенными. Открывается в браузере, без npm и установок.

## ЗАПУСК И ПРОВЕРКА

1. Распакуй ZIP **целиком**.
2. Двойным щелчком открой **`ПРОВЕРИТЬ.html`** — здесь удобно проверить весь сценарий.
3. Нажми **«Тест: 10 секунд»**: часы начнут считать 10 → 0, появится **пробное видео**, а после его окончания откроется основная сказка.
4. Есть дополнительные кнопки: **«Сразу видео»**, **«Сразу сайт»**, **«Реальный отсчёт»**.
5. Для реального подарка открывай **`index.html`** или публикуй всю папку на хостинге (Netlify Drop, GitHub Pages, Cloudflare Pages). **НЕ отправляй ей тестовую ссылку** с `?test=1`.

## КАК ПОДСТАВИТЬ СВОЁ ВИДЕО

В архив уже включён **тестовый** `media/birthday.mp4` (7 секунд). **Замени его на свой MP4 с тем же именем.** Старый файл можно удалить. Подходит H.264 в MP4 (обычный экспорт из CapCut, Premiere, DaVinci Resolve). На iPhone лучше тоже использовать обычный H.264/AAC, а не экзотические кодеки.

Можно изменить путь к видео в `countdown-config.js`, поле `videoFile`. Не трогай `index.html`, `countdown.css` и `countdown.js`, если хочешь только заменить видео.

**Важное ограничение браузеров:** в полночь видео **запустится автоматически без звука** — такова политика автозапуска Chrome/Safari и других браузеров. Для звука Алинке надо нажать видимую кнопку **«Включить звук»** в нижнем левом углу видеоплеера. Если браузер полностью блокирует автозапуск, будет большая кнопка **«Включить видео»**. После конца видео сказка откроется автоматически; есть и кнопка **«Перейти к сказке»**.

## ВРЕМЯ И ДАТА

Открой `countdown-config.js`:

```js
window.ALINKA_COUNTDOWN_CONFIG = Object.freeze({
  targetDate: '',
  videoFile: 'media/birthday.mp4',
  autoOpenSiteAfterVideo: true,
  testCountdownSeconds: 10
});
```

- `targetDate: ''` — **ближайшая 00:00 (полночь)** по времени телефона или компьютера человека, который открыл сайт. Если открывать после полуночи, это будет уже следующая полночь.
- Для точной даты ДР измени, например, на `targetDate: '2026-11-07'`. Сайт не будет назначать новую полночь после этой даты: при открытии в 00:00 или позже видео покажется **сразу**.
- Важно: время определяется **часами самого устройства**, не сервером. Если телефон показывает неверное время/часовой пояс, отсчёт тоже будет неправильным.
- Если телефон уходит в сон, при возвращении счётчик сверяется с реальным временем, а не продолжает «замороженный» интервал. Чтобы видео стартовало строго в 00:00, вкладка должна оставаться открытой и активной; в спящем режиме браузеры могут приостанавливать JavaScript и медиа.

## ЧТО ОСТАНЕТСЯ ПОСЛЕ ВИДЕО

Сказочная книга и замок; 18 порталов в мультвселенные детства с посланиями; коллекция звёзд; 18 пожеланий; оракул, тест и торт с 18 свечами; интерактивный конверт с личным поздравлением; маленькие секреты; музыка по кнопке.

На компьютере и телефоне макет адаптивный. Часть персонажей и шрифты загружаются из внешних источников — для них нужен интернет; без сети основные элементы, игры, замок, текст и локальное видео остаются доступны.
